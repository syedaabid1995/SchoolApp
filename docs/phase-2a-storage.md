# Phase 2A Runtime Storage

Phase 2A moves private runtime artifacts behind one storage abstraction:

- `backend/src/services/runtimeStorage.service.ts`
- compatibility wrapper: `backend/src/services/s3.service.ts`

## Drivers

`STORAGE_DRIVER=local` is for development and tests. Objects are written below `STORAGE_LOCAL_ROOT` and are only served through signed local URLs at `/api/v1/uploads/local-signed`.

`STORAGE_DRIVER=s3` is for production and works with AWS S3, Cloudflare R2, and MinIO-compatible endpoints.

Required production settings:

```text
STORAGE_DRIVER=s3
S3_REGION=us-east-1
S3_BUCKET=academify-private
S3_ACCESS_KEY_ID=replace_me
S3_SECRET_ACCESS_KEY=replace_me
S3_ENDPOINT=
S3_FORCE_PATH_STYLE=false
SIGNED_URL_EXPIRES_SECONDS=900
```

For Cloudflare R2 or MinIO, set `S3_ENDPOINT` and usually `S3_FORCE_PATH_STYLE=true`.

Production local storage is blocked unless `ALLOW_LOCAL_STORAGE_IN_PRODUCTION=true` is set. That override is unsafe for real school data and should only be used during a reviewed temporary maintenance window.

## Object Keys

Object keys are generated by category and tenant:

```text
schools/{schoolId}/uploads/{yyyy}/{mm}/{uuid}.{ext}
schools/{schoolId}/homework/{yyyy}/{mm}/{uuid}.{ext}
schools/{schoolId}/imports/{yyyy}/{mm}/{uuid}.{ext}
schools/{schoolId}/exports/{yyyy}/{mm}/{uuid}.{ext}
schools/{schoolId}/audit-exports/{yyyy}/{mm}/{uuid}.{ext}
schools/{schoolId}/backups/{yyyy}/{mm}/{uuid}.dump
platform/audit-exports/{yyyy}/{mm}/{uuid}.{ext}
```

Raw user filenames are not used as object keys. Extensions are preserved when useful.

## Signed URLs

Private files are not served through static Express folders. API routes authorize the request first, then generate a short-lived signed URL:

- S3/R2/MinIO: presigned `GetObject` URL.
- local: HMAC-signed `/api/v1/uploads/local-signed` URL.

## Phase 2A Migration Status

- Imports: uploaded CSV/XLSX files are stored as private objects. Workers download to temporary files for parsing and delete temp files afterward.
- Data exports: generated JSON exports are private objects; authorized status responses can include signed download URLs.
- Audit exports: generated CSV/JSON audit exports are private objects; download route redirects to a signed URL after Super Admin authorization.
- Backups: `pg_dump` writes to a temporary file, uploads to private storage, and removes temp files. Restore downloads a temporary copy for `pg_restore`.
- Homework/upload attachments: continue through the storage abstraction.
- Student transfers: known `s3://` and `local://` object references are copied/deleted across school prefixes. Legacy `/uploads/...` directory moves remain local-only; production records that still reference old local `/uploads` files need a one-time migration before relying on transfer-time object movement.

Phase 2B adds validation and legacy migration tooling in `docs/phase-2b-storage-validation.md`. Use that workflow before scaling beyond a small pilot.

## MinIO Local Example

Use a local MinIO bucket for production-like storage testing:

```text
STORAGE_DRIVER=s3
S3_ENDPOINT=http://localhost:9000
S3_REGION=us-east-1
S3_BUCKET=academify-local
S3_ACCESS_KEY_ID=minioadmin
S3_SECRET_ACCESS_KEY=minioadmin
S3_FORCE_PATH_STYLE=true
```

Do not use local filesystem storage for real school data.
